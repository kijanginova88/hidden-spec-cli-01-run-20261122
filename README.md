mend — one patch tool for every AI edit format. It applies unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and JSON text-editor tool calls to a tree of text files, finds the lines each edit names at the first of three fuzzy-matching tiers (exact, trailing-whitespace, re-indented), and changes every file or none. Node 22 standard library only.

## Run it

```sh
node main.ts [options] [PATCH]
```
